Clinch · the contract

A mistake names itself. An answer remembers where it came from.

One family, one status

Everything the library throws is a CliError and carries the status the process should leave with.

CliError ├─ UsageError 2 the line is not one we accept │ ├─ UnknownCommand + nearest command │ ├─ UnknownOption + nearest option │ ├─ MissingValue │ ├─ MissingArgument │ ├─ UnexpectedArgument │ └─ InvalidValue + what would have done └─ ConfigError 78 a file or variable we cannot use EXIT_OK 0 USAGE 2 DATA 65 NO_INPUT 66 UNAVAILABLE 69 SOFTWARE 70 IO 74 NO_PERMISSION 77 CONFIG 78 INTERRUPTED 130
